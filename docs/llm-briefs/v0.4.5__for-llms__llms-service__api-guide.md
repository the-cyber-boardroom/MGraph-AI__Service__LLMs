# MGraph-AI LLMs Service API Guide for LLMs

**Version**: v0.4.5  
**Service URL**: https://llms.dev.mgraph.ai  
**Purpose**: Guide for consuming the MGraph-AI__Service__LLMs API from Python services

## Overview

The MGraph-AI__Service__LLMs provides a unified interface to multiple LLM providers (OpenRouter, Groq, OpenAI) with built-in caching, cost optimization, and Type_Safe integration. This service handles provider routing, response caching, and cost tracking automatically.

**Key Features:**
- Multi-provider LLM access through single API
- Automatic response caching with S3 backend
- Cost tracking and optimization
- Type_Safe request/response schemas
- Provider failover and routing
- Built-in fact extraction and text analysis


## API Endpoints

### Core LLM Endpoints

#### `/llms/complete` (POST)
Execute a completion request with automatic caching.

```python
# Request
{
    "prompt": str,                              # Required: User prompt
    "model": Schema__LLM__Models,               # Required: Model enum value
    "temperature": float = 0.7,                 # Optional: 0.0-2.0
    "max_tokens": int = 1000,                   # Optional: Max tokens to generate
    "provider": Schema__Open_Router__Providers  # Optional: Force specific provider
}

# Response
{
    "model": str,
    "provider": str,
    "duration": float,
    "prompt": str,
    "response": str,       # The actual LLM response
    "usage": {
        "prompt_tokens": int,
        "completion_tokens": int,
        "total_tokens": int
    },
    "raw_response": dict   # Full provider response
}
```

#### `/llms/models` (GET)
List all available models with metadata.

```python
# Response
{
    "models": [
        {
            "id": str,         # Model identifier
            "name": str,       # Human-readable name
            "is_free": bool,   # Whether model is free
            "provider": str    # Provider name
        }
    ]
}
```

## Type_Safe Integration

Following the Type_Safe principles from the attached guide, create domain-specific schemas for API interaction:

```python
from osbot_utils.type_safe.Type_Safe import Type_Safe
from osbot_utils.type_safe.primitives.safe_str.Safe_Str import Safe_Str
from osbot_utils.helpers.llms.schemas.Safe_Str__LLM__Model_Name import Safe_Str__LLM__Model_Name
from typing import List, Dict, Literal
from enum import Enum

# Define enums for models and providers
class Enum__LLM__Models(str, Enum):
    MISTRAL_SMALL_FREE = "mistralai/mistral-small-3.2-24b-instruct:free"
    MOONSHOT_KIMI_FREE = "moonshotai/kimi-k2:free"
    GEMINI_2_FLASH     = "google/gemini-2.0-flash-lite-001"
    GPT_4O_MINI        = "openai/gpt-4o-mini"
    GPT_OSS_120B       = "openai/gpt-oss-120b"

class Enum__Open_Router__Providers(str, Enum):
    AUTO      = "auto"
    CEREBRAS  = "cerebras"
    GROQ      = "groq"
    TOGETHER  = "together"
    DEEPINFRA = "deepinfra"

# Request schemas
class Schema__LLM__Complete_Request(Type_Safe):
    prompt      : Safe_Str__LLM__Prompt
    model       : Enum__LLM__Models            = Enum__LLM__Models.MISTRAL_SMALL_FREE
    temperature : float                         = 0.7
    max_tokens  : int                           = 1000
    provider    : Enum__Open_Router__Providers = Enum__Open_Router__Providers.AUTO

# Response schemas
class Schema__LLM__Complete_Response(Type_Safe):
    model    : Safe_Str__LLM__Model_Name
    provider : str
    duration : float
    response : Safe_Str
    usage    : Dict[str, int]

# Fact extraction schemas
class Schema__Fact(Type_Safe):
    fact       : str
    confidence : float
    category   : Literal["date", "person", "location", "number", "event", "organization", "other"]

class Schema__Facts_Response(Type_Safe):
    cache_id : Safe_Str
    facts    : List[Schema__Fact]
    summary  : str
```

## Service Client Implementation

Create a Type_Safe client for the LLMs service:

```python
from osbot_utils.type_safe.Type_Safe import Type_Safe
from osbot_utils.utils.Http import POST_json, GET_json
from typing import Optional

class Client__MGraph_AI__LLMs(Type_Safe):
    base_url : str = "https://llms.dev.mgraph.ai"
    
    def complete(self, request: Schema__LLM__Complete_Request
                 ) -> Schema__LLM__Complete_Response:
        """Execute LLM completion with caching"""
        
        endpoint = f"{self.base_url}/llms/complete"
        response = POST_json(endpoint, data=request.json())
        
        return Schema__LLM__Complete_Response.from_json(response)
    
    def extract_facts(self, text          : str,
                            model         : Enum__LLM__Models = Enum__LLM__Models.GPT_OSS_120B
                      ) -> Schema__Facts_Response:
        """Extract facts from text"""
        
        endpoint = f"{self.base_url}/llms/extract-facts"
        response = POST_json(endpoint, data={
            "text_content": text,
            "model": model.value
        })
        
        return Schema__Facts_Response.from_json(response)
    
    def get_cached_response(self, cache_id: str) -> Optional[dict]:
        """Retrieve cached response by ID"""
        
        endpoint = f"{self.base_url}/cache/entry-by-id/{cache_id}"
        response = GET_json(endpoint)
        
        if response.get("status") == "success":
            return response.get("data")
        return None
```

## FastAPI Service Integration

Following the FastAPI integration patterns from the Type_Safe guide:

```python
from osbot_fast_api.api.routes.Fast_API__Routes import Fast_API__Routes

class Routes__News_Analysis(Fast_API__Routes):
    tag        : str                    = 'news-analysis'
    llm_client : Client__MGraph_AI__LLMs
    
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self.llm_client = Client__MGraph_AI__LLMs()
    
    def analyze_article(self, article_url : Safe_Str__Url           ,
                              model       : Enum__LLM__Models = None
                        ) -> Schema__Article_Analysis:
        """Analyze news article using LLMs service"""
        
        # Fetch article content
        article_text = self.fetch_article(article_url)
        
        # Extract facts using LLMs service
        facts_response = self.llm_client.extract_facts(
            text  = article_text,
            model = model or Enum__LLM__Models.GPT_OSS_120B
        )
        
        # Generate summary
        summary_request = Schema__LLM__Complete_Request(
            prompt      = f"Summarize this article: {article_text[:2000]}",
            model       = model or Enum__LLM__Models.MISTRAL_SMALL_FREE,
            temperature = 0.3,
            max_tokens  = 500
        )
        summary_response = self.llm_client.complete(summary_request)
        
        return Schema__Article_Analysis(
            url       = article_url,
            facts     = facts_response.facts,
            summary   = summary_response.response,
            cache_ids = {
                "facts"  : facts_response.cache_id,
                "summary": summary_response.get("cache_id")
            }
        )
    
    def setup_routes(self):
        self.add_route_post(self.analyze_article)
```

## Caching Strategy

The service implements multi-level caching:

1. **Request-level caching**: Identical requests return cached responses
2. **Provider-level caching**: Model availability cached for 6 hours
3. **Chat completion caching**: Responses cached for 24 hours

Cache keys are generated from:
- Model ID
- Prompt content
- Temperature and other parameters
- Provider preferences

To leverage caching effectively:

```python
# Consistent requests benefit from caching
request = Schema__LLM__Complete_Request(
    prompt      = "Explain quantum computing",
    model       = Enum__LLM__Models.GPT_OSS_120B,
    temperature = 0.7,  # Use consistent temperature
    max_tokens  = 1000  # Use consistent max_tokens
)

# First call: ~2-3 seconds
response1 = llm_client.complete(request)

# Subsequent calls: <100ms (from cache)
response2 = llm_client.complete(request)

# Check if response was cached
if response2.get("from_cache"):
    print(f"Used cached response: {response2['cache_id']}")
```

## Provider Routing

Control which provider handles your request:

```python
# Let service auto-select (default)
request.provider = Enum__Open_Router__Providers.AUTO

# Force specific provider for consistency
request.provider = Enum__Open_Router__Providers.GROQ  # Fast inference

# Provider-specific benefits:
# - GROQ: Fastest inference (~100ms)
# - CEREBRAS: High throughput
# - TOGETHER: Good for large batches
# - DEEPINFRA: Cost-effective
```
