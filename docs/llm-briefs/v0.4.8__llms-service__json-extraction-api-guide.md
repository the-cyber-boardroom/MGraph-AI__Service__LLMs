# LLM Service - JSON Extraction API Guide

**Service URL**: `https://llms.dev.mgraph.ai`  
**Endpoint**: `/platform/open-router/llm-json/extract`  
**Version**: 0.4.8  
**Purpose**: Extract structured JSON data from text using LLM with built-in caching

## Critical Design Principle: Type_Safe First

**IMPORTANT**: This service is designed to work transparently with Type_Safe classes. All clients should:
1. Define their data structures as Type_Safe classes
2. Use `Type_Safe__To__Json` transformer to convert to JSON Schema
3. Call the extraction endpoint with the generated schema
4. Convert responses back to Type_Safe instances using `.from_json()`

This pattern ensures type safety throughout your entire application pipeline, from schema definition through to data usage.

## Overview

The JSON extraction endpoint allows you to send unstructured text and receive structured JSON that matches your specified schema. The service handles LLM provider routing, response caching, and automatic retries, ensuring consistent and cost-effective data extraction.

## Quick Start - The Type_Safe Way

**CRITICAL**: All clients should use Type_Safe classes, not raw JSON schemas. The `Type_Safe__To__Json` transformer (available in OSBot-Fast-API) provides transparent conversion between Type_Safe classes and JSON schemas.

```python
class test_qa__from_doc__LLM_Service__JSON_Extraction_API_Guide(TestCase):
    def test__http__llm_json__extract(self):
        import requests
        from osbot_utils.utils.Env                                  import get_env, load_dotenv
        from osbot_utils.type_safe.Type_Safe                        import Type_Safe
        from osbot_fast_api.api.transformers.Type_Safe__To__Json    import Type_Safe__To__Json
        from osbot_fast_api.schemas.consts__Fast_API                import ENV_VAR__FAST_API__AUTH__API_KEY__NAME
        from osbot_fast_api.schemas.consts__Fast_API                import ENV_VAR__FAST_API__AUTH__API_KEY__VALUE
        
        
        load_dotenv()
        
        headers = { get_env(ENV_VAR__FAST_API__AUTH__API_KEY__NAME): get_env(ENV_VAR__FAST_API__AUTH__API_KEY__VALUE) }

        # 1. Define your data structure as a Type_Safe class
        class Schema__Company_Info(Type_Safe):
            company_name      : Safe_Str__Display_Name
            revenue           : Safe_Float__Money
            revenue_str       : Safe_Str__Text__Dangerous       # we should be using a type like Safe_Str__Money or Safe_Str__Dollars
            growth_percentage : Safe_Float__Percentage_Exact
            fiscal_period     : Safe_Str__Topic
            year              : Safe_UInt
            quarter           : Safe_UInt

        # 2. Convert Type_Safe to JSON Schema (transparent operation)
        transformer  = Type_Safe__To__Json()
        output_schema = transformer.convert_class(Schema__Company_Info)
        text_content  = "TechCorp reported Q3 2024 revenue of $5.2 million, a 30% increase year-over-year."

        # 3. Make the extraction request
        response = requests.post(url   = "https://llms.dev.mgraph.ai/platform/open-router/llm-json/extract",
                                json   = { "text_content" : text_content        ,
                                           "output_schema": output_schema       ,
                                           "model"        : "openai/gpt-oss-20b",
                                           "provider"     : "groq"              },
                                headers = headers        )
        assert response.status_code == 200

        # 4. Convert response back to Type_Safe instance (type-safe operation)
        result       = response.json()
        company_info = Schema__Company_Info.from_json(result["json_data"])

        # Now you have a fully typed object :)
        assert company_info.json() == { 'company_name'     : 'TechCorp'       ,
                                        'fiscal_period'    : 'Q3 2024'        ,
                                        'growth_percentage': 30.0             ,
                                        'quarter'          : 3                ,
                                        'revenue'          : 5200000.0        ,
                                        'revenue_str'      : '$5.2 million'   ,
                                        'year'             : 2024             }
        assert company_info.obj() == __(company_name      = 'TechCorp'      ,
                                        revenue           = 5200000.0       ,
                                        revenue_str       = '$5.2 million'  ,
                                        growth_percentage = 30.0            ,
                                        fiscal_period     = 'Q3 2024'       ,
                                        year              = 2024            ,
                                        quarter          = 3                )
```

|-------|------|----------|-------------|---------|
| `text_content` | string | Yes      | Text to extract data from (max 32KB) | - |
| `output_schema` | object | Yes      | JSON Schema defining expected structure | - |

## Type_Safe Schema Guidelines

### Why Type_Safe Instead of Raw JSON Schemas

While the endpoint accepts JSON Schema format, **you should always define your schemas as Type_Safe classes** and use `Type_Safe__To__Json` for conversion. This ensures:

1. **Type preservation** throughout your application
2. **Automatic validation** at every step
3. **IDE support** with autocomplete
4. **Single source of truth** for data structures

### Basic Type_Safe Patterns


When you pass a Type_Safe class to `Type_Safe__To__Json.convert_class()`, it automatically:
- Maps Type_Safe types to JSON Schema types
- Handles nested Type_Safe objects recursively
- Preserves constraints and validations
- Generates proper `required` arrays
- Handles Safe primitives correctly

The service automatically caches responses for 24 hours based on:
- Text content
- Output schema
- Model selection
- Temperature setting

**Cache benefits:**
- Identical requests return instantly (< 100ms)
- No additional LLM costs for cached responses
- Same `cache_id` returned for identical requests
- Cache persists across service restarts

## Python Client Example - Type_Safe Pattern

**This is the recommended approach** - using Type_Safe classes throughout your application:

```python
from osbot_utils.type_safe.Type_Safe import Type_Safe
from osbot_fast_api.api.transformers.Type_Safe__To__Json import Type_Safe__To__Json
from typing import List, Optional
import requests

class LLMJsonExtractor:
    """Client for JSON extraction using Type_Safe classes."""
    
    def __init__(self, base_url: str = "https://llms.dev.mgraph.ai"):
        self.base_url = base_url
        self.endpoint = f"{base_url}/platform/open-router/llm-json/extract"
        self.transformer = Type_Safe__To__Json()  # Transformer for Type_Safe -> JSON Schema
    
    def extract_typed_data(self, 
                          text: str,
                          schema_class: Type[Type_Safe],  # Pass Type_Safe class directly!
                          model: str = "openai/gpt-oss-20b",
                          provider: str = "groq") -> Type_Safe:
        """
        Extract structured data from text using Type_Safe schema.
        
        The key insight: We pass a Type_Safe CLASS, not a JSON schema.
        The conversion happens transparently.
        
        Args:
            text: Input text to analyze
            schema_class: Type_Safe class defining expected structure
            model: LLM model to use
            provider: Provider for routing
            
        Returns:
            Instance of schema_class with extracted data (fully typed!)
        """
        # Step 1: Convert Type_Safe class to JSON Schema (transparent)
        json_schema = self.transformer.convert_class(schema_class)
        
        # Step 2: Call API with generated schema
        response = requests.post(
            self.endpoint,
            json={
                "text_content": text,
                "output_schema": json_schema,
                "model": model,
                "provider": provider,
                "temperature": 0.0,  # Deterministic
                "max_tokens": 5000
            }
        )
        response.raise_for_status()
        
        # Step 3: Convert JSON response back to Type_Safe instance
        result = response.json()
        json_data = result["json_data"]
        
        # This is the magic - full type safety preserved!
        return schema_class.from_json(json_data)

# - Automatic validation

# - All Type_Safe methods available
```

### Error Handling

```python
def safe_extract(extractor, text, schema):
    try:
        result = extractor.extract(text, schema)
        return result["json_data"], None
    except requests.HTTPError as e:
        if e.response.status_code == 400:
            return None, f"Invalid schema: {e.response.json()}"
        elif e.response.status_code == 422:
            return None, f"Missing required fields: {e.response.json()}"
        else:
            return None, f"API error: {str(e)}"
    except Exception as e:
        return None, f"Unexpected error: {str(e)}"

data, error = safe_extract(extractor, text, schema)
if error:
    print(f"Extraction failed: {error}")
else:
    print(f"Extracted data: {data}")
```
